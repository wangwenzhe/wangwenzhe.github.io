禅道

发表于2020-05-25|更新于2025-06-16|项目管理禅道
|总字数:449|阅读时长:1分钟|浏览量:

简介

产品管理、项目管理、测试管理、部门管理、人员管理、需求管理、任务管理等

下载

https://www.zentao.net/download/zentaopms12.3.1-80220.html

页面下拉，选择合适版本下载

安装

https://www.zentao.net/book/zentaopmshelp/76.html

  1. 安装必须指定到 C盘或 D盘等根目录，比如 c:\xampp，或者 d:\xampp

  2. 修改数据库密码，禅道服务启动后，会提示数据库密码太弱。菜单：密码-数据库密码「root 用户密码」

  3. Apache 用户访问验证，启用访问验证后「此帐号密码需要提供给所有禅道登录人员」，用户先要进入登录验证页面，成功后进入登录页面「登录页面需要输入禅道的登录帐号方可登录，默认登录禅道帐号：admin 123456」，不建议开启Apache 用户访问验证

  4. 超级管理员登录密码修改，可以到 后台 – 安全 页面进行修改「禅道账户密码」

  5. 登录禅道数据库，默认只能在服务器本机登录。可以通过将 mysql/my.ini 文件中 bind-address = 127.0.0.1 改为bind-address = 0.0.0.0

    数据库登录信息参考xampp/zentao/config/my.php 里的对应参数

服务器迁移

  1. 禅道服务停止
  2. 将 xampp 压缩，拷贝到目标机器上
  3. 解压
  4. 启动

注意：1. 程序包和数据都在里面 2. 占用端口 8090 3306，不要与其它冲突

问题

  1. 缺少 tmp 目录导致数据库连接失败

  2. 备份文件一直增加到磁盘占满，导致系统卡死

    解决：定时删除 backup 目录
