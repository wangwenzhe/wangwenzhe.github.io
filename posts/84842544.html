GitHub-SSH加密

发表于2019-07-11|更新于2025-06-16|开发工具GitHub
|总字数:354|阅读时长:1分钟|浏览量:

原理

  1. 客户端使用 SSH 生成非对称密钥对，其中公钥信息保存在 GitHub 站点密钥中。
  2. 客户端发送数据「代码」前，使用本地私钥加密，GitHub 收到数据后，使用对应公钥解密得到源代码。

Windows 生成密钥对

  1. 安装 git 工具

  2. 右键选择「Git Bash here」，打开终端

  3. 进入 C:\Users\Administrator\.ssh 目录，没有则手动创建「Linux 为 ~/.ssh」

  4. 生成 key

  5. 使用notepad++ 打开 id_rsa.pub，拷贝内容

  6. 登录 GitHub ，点击右上角头像，选择 Setting，点击 SSH and GPG keys，点击 New SSH key，Title 输入 wangwz2012@sina.cn「客户端账户标识」，将步骤5中拷贝内容粘贴至Key 文本域中，点击 Add SSH key

  7. 测试 ssh key 是否配置成功

  8. 查看 git 本地配置账号信息

  9. 推送本地仓库数据至远程仓库
