音视频通信功能及技术标准要求

发表于2020-10-13|更新于2025-06-16|音视频
|总字数:458|阅读时长:1分钟|浏览量:

功能要求

  1. 语音通话：即两人或多人语音通话，支持 48kHz，支持双声道。最多支持300人同时在线，最多支持50人同时开启麦克风
    1. Web 和 Android 端支持关闭麦克风
  2. 视频通话：即两人或多人视频通话，支持720P、1080P高清画质。最多支持300人同时在线，最多支持50人同时开启摄像头
    1. Web 端支持切换摄像头和麦克风，Android 端支持切换摄像头
    2. Web 和 Android 端支持关闭摄像头和麦克风

性能要求

  • 低延时

    提供高连通、高可靠、强安全的网络连接通道，保证链路端到端平均时延 < 500ms

  • 低卡顿

    降低卡顿率，弱网环境下，能够保证高质量的音视频通信，确保音视频通信过程顺畅稳定

  • 高品质

    支持 720P、1080P 高清画质，70%丢包率可正常视频。音频方面支持 48kHz 采样率，128kbps 码率，80%丢包率可正常语音

技术要求

  1. 音视频后台服务能够在内网和互联网环境中独立部署、运行并提供持续、稳定服务
  2. 提供 Web、Android 平台的 SDK 便于开发者快速集成并与实时音视频服务后台连通
  3. Web、Android 各端之间能够互联互通
  4. Android 端支持 Android 4.1（SDK API Level 16）及以上系统运行
  5. Web 端支持 Windows 7 及以上版本的 Chrome 56+ 版本以上浏览器中运行

其它

  1. 提供搭建好的音视频后台服务，在内网或互联网环境中部署、运行正常
  2. 提供的 Web 、Android SDK，接口文档和示例程序要规范、有效，能够让开发者快速入门和开发
  3. 提供高效的技术支持服务
